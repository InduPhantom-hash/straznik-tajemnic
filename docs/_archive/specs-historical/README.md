# 🗄️ Archiwum Historycznych Specyfikacji (v0.9.x)

Ten katalog zawiera historyczne dokumenty koncepcyjne, notatki techniczne i specyfikacje wdrożeniowe z wczesnych etapów badawczych i deweloperskich projektu **Strażnik Tajemnic AI** (lipiec - sierpień 2026 r.).

Dokumenty te zostały w pełni skonsumowane przez stabilną bazę kodu wersji **v0.9.5** oraz oficjalną dokumentację w katalogu `docs/`. Zostały zarchiwizowane w tym miejscu w celach referencji inżynieryjnej, zgodnie z zasadą zachowania historii i eliminacji konkurencyjnych plików stanu z głównego katalogu repozytorium.

## Spis zarchiwizowanych dokumentów:
- `architektura.md` - wczesny szkic wielowarstwowej architektury promptów i routingu modeli
- `spec-audit-image-rendering-and-era-consistency.md` - audyt renderowania obrazów scen i spójności epok
- `spec-biografia.md` - wstępna unifikacja życiorysów badaczy
- `spec-biografie-strefa11.md` - specyfikacja postaci dla polskich scenariuszy Strefy 11
- `spec-dossier-layout-and-image-refactor.md` - założenia przebudowy układu akt śledztwa
- `spec-event-adjudication-concordia.md` - szkic mechaniki uniku i rozstrzygania starć
- `spec-idea-roll-investigation-board.md` - pierwotna koncepcja Rzutu na Pomysł i korkowej tablicy dowodów
- `spec-image-cropping-fixes.md` - wytyczne formatów kadrowania (proporcje 4:3, 16:9)
- `spec-journal-improvements-and-deduction.md` - założenia Dziennika Śledztwa i wnioskowania
- `spec-legacy-journal-cleanup.md` - plan oczyszczenia zduplikowanych wpisów dziennika
- `spec-manual-setup-fix.md` - szkic poprawki trybu ręcznego wyboru badacza
- `spec-quick-setup-fix.md` - specyfikacja szybkiego startu sesji

Jedynym źródłem prawdy (SSOT) dla bieżących zadań i błędów jest oficjalny rejestr **GitHub Issues**.
