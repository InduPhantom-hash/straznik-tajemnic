# Strażnik Tester (Vibe-coding)

Skrypty testowe, konfiguracje testowe i procedury uruchomieniowe dla silnika straznik-tajemnic.

## Zgłaszanie uwag i błędów (Program Beta)

Testerzy zewnętrzni mogą przekazywać informacje zwrotne na dwa sposoby:
1. **W aplikacji:** Klikając "Zgłoś uwagę lub błąd" w lewym menu lub na ekranie powitalnym. Modal pozwala wysłać e-mail jednym kliknięciem, skopiować raport Markdown pod GitHub Issue lub pobrać plik diagnostyczny JSON.
2. **Bezpośredni e-mail:** Przesyłając opis problemu i plik diagnostyczny na dedykowany adres: `issue@callofchtulhu.pl`.
3. **GitHub Issues:** Tworząc zgłoszenie w oficjalnym trackerze GitHub.
